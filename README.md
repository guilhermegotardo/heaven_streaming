## Project structure

```
lib/
├── main.dart
├── app/
│   ├── app_widget.dart
│   └── routes.dart
├── dat/
│   └── catalog/
│       ├── catalog.dart                       # Catalog / Video / Episode models
│       ├── catalog.g.dart                     # generated by build_runner
│       ├── catalog_controller.dart            # loads and caches the catalog
│       ├── library_catalog_data_source.dart   # fetches catalog.json over HTTP
│       └── media_library.dart                 # library base URL and path resolution
└── features/
    ├── splash/
    │   └── presentation/
    │       ├── splash_page.dart
    │       └── splash_controller.dart
    ├── home/
    │   └── presentation/
    │       ├── home_page.dart                 # hero + poster rows, Home/Series/Movies filter
    │       └── widgets/                       # hero banner, top bar, loading skeleton
    ├── details/
    │   └── presentation/
    │       └── details_page.dart              # title details + episode list per season
    └── player/
        ├── media_player.dart                  # player with controls and auto-play next
        └── play_video.dart                    # opens the player for a movie or episode
```

Shared UI lives in `lib/core/`:

```
lib/core/
├── theme/        # app_theme.dart + app_tokens.g.dart (generated from design/tokens)
├── utils/        # video_display.dart (labels, sorted episodes, seasons)
└── widgets/      # poster card, content row, episode tile, buttons, badges, states

tool/
└── serve_library.dart                         # dev server for the video library
```


## Video library (local until v2.0)

Videos are not bundled with the app. They live in a folder served over HTTP:

```
example_library/
├── catalog.json        # metadata; paths relative to the folder
└── m001/
    ├── video.mp4
    └── poster.jpg
```

Series have no `videoPath`; instead they carry an `episodes` list:

```json
{
  "id": "m001",
  "title": "O Pequeno Urso",
  "posterPath": "m001/poster.png",
  "episodes": [
    {
      "season": 1,
      "number": 1,
      "title": "Brincando na Neve",
      "videoPath": "m001/O_Pequeno_Urso/SEASON_1-1/O Pequeno Urso - S01E01 - Brincando na Neve.mp4"
    }
  ]
}
```

Run it in two terminals:

```bash
# 1. Library server (port 8081; accepts another folder/port)
dart run tool/serve_library.dart                      # uses example_library
dart run tool/serve_library.dart ~/Videos/Gotflix 8081

# 2. App
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
flutter run -d linux
```

On the web, the app fetches the library from the same host that served it, on port 8081.
On desktop, from `localhost:8081`. For another address:

```bash
flutter run -d linux --dart-define=LIBRARY_URL=http://192.168.0.10:8081/
```

After changing `lib/dat/catalog/catalog.dart`, regenerate the code:

```bash
dart run build_runner build --delete-conflicting-outputs
```
